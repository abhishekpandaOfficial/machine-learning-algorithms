# Logistic Regression — Insurance Fraud Detection

**Project 2** in the `machine-learning-algorithms/01-logistic-regression/` portfolio.

## Purpose

Educational binary-classification example using Logistic Regression to predict the dataset's `fraud_reported` label. It is not a fraud determination system and must not be used to deny claims, set premiums, or make consequential decisions about individuals.

## Methodology

- Stratified train/test split with fixed random seed.
- Numeric median imputation and standardization.
- Categorical most-frequent imputation and one-hot encoding.
- Preprocessing and Logistic Regression in one scikit-learn `Pipeline`.
- `class_weight="balanced"` baseline to address label imbalance; compare against alternatives during model review.
- Held-out metrics: accuracy, precision, recall, F1, ROC-AUC, average precision.
- Notebook plots: target distribution, feature histograms, confusion matrix, ROC curve, precision-recall curve, and probability distribution.

Threshold 0.50 is a baseline, not an operationally optimized decision threshold. Any threshold selection should use a validation set and a documented cost/benefit analysis, not the final test set.

## Responsible-use and leakage warning

The source describes claim-level fields and historical fraud labels. Some features may be created during or after an investigation. The notebook excludes obvious identifier candidates but cannot automatically determine feature timing. Before prospective use, review feature definitions, remove post-outcome fields, check leakage, evaluate calibration and subgroup performance, and obtain legal, privacy, and domain review. This project is for education only.
