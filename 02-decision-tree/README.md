# Decision Tree Classifier

This folder contains two domain projects that teach Decision Tree classification from fundamentals through deployment.

## Projects

1. [Telecom Customer Churn](01-telecom-customer-churn/README.md)
2. [Transaction Fraud Classification](02-transaction-fraud-classification/README.md)

## Learning lifecycle

Each project will follow the same sequence:

1. Problem definition and intended use
2. Dataset sourcing, licence/terms review, and data dictionary
3. Exploratory data analysis (EDA)
4. Data quality checks and preprocessing
5. Train/validation/test split and leakage prevention
6. Baseline model and Decision Tree theory
7. Model training and justified hyperparameter tuning
8. Evaluation and error analysis
9. MLflow experiment tracking
10. Reusable pipeline, saved artifacts, and metadata
11. Automated tests
12. Streamlit application and deployment
13. Executed Jupyter notebook with saved outputs
14. HTML and PDF exports, reviewed before publishing
15. README, reproducibility instructions, limitations, and public links

## Publishing rules

- Keep the raw data out of Git unless redistribution permission is clearly established.
- Record the dataset source, applicable terms/licence, download date, and checksum when appropriate.
- Never claim a public deployment or an export is complete until it has been built and verified.
- Keep the notebook educational: explain each major code block and show its output.
- Treat fraud and churn predictions as educational decision-support examples, not as automated consequential decisions.
