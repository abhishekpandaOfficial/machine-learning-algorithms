# Reinforcement Learning

Reinforcement learning learns a policy through interaction with an environment and feedback from rewards.

## Core concepts

- State, action, reward and episode
- Policy and value function
- Exploration versus exploitation
- Discount factor and return
- Markov Decision Processes
- Offline evaluation and safety constraints

## Algorithm backlog

Multi-Armed Bandits · Q-Learning · SARSA · Deep Q-Networks · Policy Gradients · Actor-Critic
