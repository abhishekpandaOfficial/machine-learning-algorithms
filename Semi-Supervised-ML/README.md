# Semi-Supervised Machine Learning

Semi-supervised learning combines a small labelled dataset with a larger unlabelled dataset.

## Planned concepts

- Label propagation and label spreading
- Pseudo-labelling and confidence thresholds
- Consistency regularisation
- Validation when labels are scarce
- Confirmation bias and noisy pseudo-labels
