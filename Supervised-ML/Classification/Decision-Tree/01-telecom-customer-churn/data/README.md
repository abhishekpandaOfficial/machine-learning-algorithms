# Dataset handling

The notebook downloads a candidate IBM Telco Customer Churn CSV into this directory when you run it.

- Context: https://www.ibm.com/docs/en/ws-and-kc?topic=tutorials-predict-telecommunications-churn
- Candidate CSV URL: https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

Before sharing or redistributing the raw CSV, independently verify the licence/terms that apply to the dataset itself. A repository code licence does not automatically license its data. Raw data is ignored by Git by default.

If the download URL fails, stop and verify the source and its terms rather than substituting an undocumented copy.
