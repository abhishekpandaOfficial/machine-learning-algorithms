# Visual assets

- `decision_tree_cover.svg`: original diagram created for this educational repository.
- `ml_lifecycle.svg`: original diagram created for this educational repository.

These SVG diagrams were authored for this project and do not contain third-party images. They are intended to illustrate the learning sequence and a generic decision-tree structure, not measured model results.

Notebook plots (class distribution, Gini curve, confusion matrix, tree diagram, feature importance) are generated by notebook code cells so they are reproducible and their outputs are included when the notebook is executed and exported.
