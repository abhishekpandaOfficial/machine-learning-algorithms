# Supervised ML — Classification

Classification predicts a discrete class, such as `fraud` versus `legitimate`, or estimates a probability for each class.

## Core concepts

- Binary, multiclass and multilabel classification
- Decision boundaries and class probabilities
- Confusion matrices and error costs
- Accuracy, precision, recall, F1, ROC-AUC and PR-AUC
- Threshold selection and probability calibration
- Class imbalance, resampling and class weights
