# Supervised ML — Regression

Regression predicts a continuous numeric target, such as price, demand, duration or risk amount.

## Core concepts

- Linear and nonlinear relationships
- Residuals and error distributions
- MAE, MSE, RMSE and $R^2$
- Regularisation and feature scaling
- Cross-validation and prediction intervals
- Data drift and extrapolation risk

## Algorithm backlog

Linear Regression · Ridge · Lasso · Elastic Net · Decision Tree Regressor · Random Forest Regressor · Gradient Boosting Regressor
