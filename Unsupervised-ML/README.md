# Unsupervised Machine Learning

Unsupervised learning finds structure when no labelled target is available.

## Planned tracks

- Clustering — group similar observations.
- Dimensionality reduction — represent data with fewer informative dimensions.
- Anomaly detection — identify unusual observations without trusted labels.
- Association discovery — find co-occurring items or behaviours.

## Algorithm backlog

k-Means · Hierarchical Clustering · DBSCAN · Gaussian Mixture Models · PCA · Isolation Forest · Association Rules
