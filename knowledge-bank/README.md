# Machine Learning Knowledge Bank

This directory is the long-term, version-controlled source for the Machine Learning Knowledge Academy.

## Content principles

1. Keep Markdown as the human-editable source of truth.
2. Give every question a stable, unique ID.
3. Include difficulty, type, tags, a direct answer, a practical example, a common pitfall, and a practice prompt.
4. Keep code examples lightweight and runnable on modest hardware; use cloud notebooks only when a task genuinely needs more compute.
5. Review factual correctness, duplication, clarity, and runnable code before publishing.

## Growth plan

Expand in reviewed batches of 50–100 questions toward 1,200+ entries. Suggested later collections: mathematics and statistics, Python/data tooling, supervised algorithms, unsupervised learning, feature engineering, evaluation, deep learning, time series, recommendation, MLOps, responsible AI, and ML system design.
