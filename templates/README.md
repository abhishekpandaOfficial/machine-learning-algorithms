# Machine Learning Project Templates

Use the template that matches the learning paradigm and target type. Copy the relevant template into a new numbered project folder, then replace the placeholders with project-specific content.

- [Classification](classification/README.md)
- [Regression](regression/README.md)
- [Unsupervised learning](unsupervised/README.md)
- [Semi-supervised learning](semi-supervised/README.md)
- [Reinforcement learning](reinforcement/README.md)

Every project should include a notebook, README, requirements file, tests, artifacts directory, optional Streamlit app, and reviewed HTML/PDF exports.
