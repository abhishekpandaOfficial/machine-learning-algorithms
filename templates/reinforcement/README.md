# Reinforcement Learning Project Template

## Required sections

1. Environment, state, action and reward definitions
2. Safety constraints and prohibited actions
3. Markov Decision Process assumptions
4. Return and discount-factor mathematics
5. Exploration policy and reproducibility seed
6. Training curves and evaluation episodes
7. Baseline policy and offline evaluation limits
8. Failure cases and reward-hacking analysis
9. Save/reload policy smoke test
10. HTML/PDF export and final checklist

## Definition of done

- [ ] Rewards represent the intended objective and do not invite harmful shortcuts.
- [ ] Evaluation is separated from training episodes.
- [ ] Exploration and randomness are documented.
- [ ] Safety constraints and human override are explicit.
- [ ] Outputs are reproducible and print-ready.
