# Unsupervised Project Template

Document the problem without assuming a trusted target.

## Required sections

1. Business question and why labels are unavailable
2. Dataset source, terms and feature dictionary
3. Scaling, missing values and leakage considerations
4. Algorithm intuition and objective function
5. Choosing the number of groups or dimensions
6. Stability, sensitivity and qualitative validation
7. Visualisation and practical interpretation
8. Failure cases and ethical limitations
9. Save/reload artifact smoke test
10. HTML/PDF export and final checklist

## Definition of done

- [ ] The discovered structure is not described as ground truth.
- [ ] Sensitivity to seeds, scaling and hyperparameters is reported.
- [ ] A human review plan is documented.
- [ ] Outputs are reproducible and print-ready.
